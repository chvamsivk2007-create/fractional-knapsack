# Fractional Knapsack 🎒

C++ program to solve the **Fractional Knapsack Problem** using the Greedy approach.

---

## 📖 Description
- Sort items by value/weight ratio
- Pick items with highest ratio first
- Allow fractional selection of items
- Time Complexity: O(n log n)

---

## ▶️ Compilation & Run
```bash
g++ fractional_knapsack.cpp -o fractional_knapsack
./fractional_knapsack
